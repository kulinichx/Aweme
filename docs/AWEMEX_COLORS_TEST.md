# 图层 2.6.2 配色移植：测试说明

目标环境：iPad / 抖音 32.6 / 用户已有巨魔注入流程。此文件不是设备验证报告。
本组仅颜色移植；设置搜索、长按下载不在此提交中。

## 开启方式（DYYY设置 → 第一组/视频设置）

- 弹幕：开启 **启用弹幕改色** 和 **图层弹幕亮色**。
- 左下发布时间及IP：开启 **时间属地显示** 和 **图层时间/属地渐变**。
- 两个新开关默认关闭，不迁移、不覆盖已有自定颜色。
- 图层模式开启时，优先于同区域旧配色；关闭后保留原自定颜色/旧随机模式。
- **进度标签颜色**仍是播放时长配色，不属于左下发布时间，未改动。
- 右上角透明但可点击的现有实现没有改动。

## 原算法与适配边界

二进制依据：用户提供的抖音图层2.6.2，AwemeX.dylib SHA256
`38b2b0f63d0662f55ea1b122bbb57df32cc17b6eb960526d6a3731013134b1d7`。
没有合并/加载原 dylib，也没有复制其整个菜单或其他功能。

### 保留的核心算法

- 弹幕 hook `AWEDanmakuContentLabel.setTextColor:`：RGB各通道
  `(128 + arc4random_uniform(128)) / 255.0`，alpha=1。
  该分支调用原 setter，不使用 DYYY 的 `_randomColor`。
  图层分支描边宽度0.1、描边颜色nil；关闭图层模式保持旧描边逻辑。
- 左下 `AWEPlayInteractionTimestampElement.timestampLabel`：
  `2 + arc4random_uniform(2)` 色，横向(0,0.5)→(1,0.5)。
- 每色 H=`(random&255)/256`，S=`0.5+(random&127)/256`，
  B=`0.6+(random%102)/256`，alpha=1；3色locations=0/0.5/1。
- 现有标签layer截图的alpha作为渐变mask；不先隐藏文字、不先强制置白。
- 发布时间和IP属地是同一标签整体渐变，不是两个独立调色板。
- 普通getter应用重新取色；IP文本异步更新后重新应用颜色。
- 未修改 DYYY 全局 `random`、`random_gradient`、`rainbow_rotating` 的含义。

### 明确增加的安全适配（不是声称原版已有）

- 只移除本功能持有的渐变层，避免删除App自己的layer。
- 空bounds等待真正布局重试，不递归向主队列无限投递。
- 旋转、尺寸/文字/字体变化时重建mask，布局修复沿用上次palette避免每帧换色。
- 开关关闭清理自有旧层；设置页改色会刷新弱引用跟踪的时间标签。
- 渲染大小校验、主线程约束、重入保护；失败保留原文字。
- 异步属地请求使用每次请求独立token，空cityCode也使旧请求失效。
  回调读当前设置，不携带过期颜色；关掉属地显示后不再写回文本。

## 本地算法测试

在有C编译器的环境执行（只测纯数值，不需要UIKit，不连接手机）：

```sh
cc -std=c11 -O2 -Wall -Wextra -Werror tests/test_awemex_palette.c -lm -o /tmp/test_awemex_palette
/tmp/test_awemex_palette
```

覆盖全部128个RGB通道值、HSB端点、2/3色数量及100000个输入与ARM64 `%102`
乘法/移位等价表达式的对照。通过并不代表UIKit或目标App兼容性已经验证。

## 真机验收（由用户在原有注入流程中测试）

1. 两个新开关均关闭：旧自定色/旧随机配色仍可用；右上角看不见但可以点击。
2. 图层弹幕模式：浅亮纯色，而非每条文字多色渐变；切换视频、开关和自定色观察。
3. 图层左下模式：发布时间和IP整行横向渐变；中国/国外/空cityCode都检查。
4. 快速上下切视频、回到同一视频、横竖屏旋转：无旧文字mask、叠层或边缘裁切。
5. 国外属地查询未返回时关闭图层模式/改自定色/切换视频：旧回调不能恢复旧配色。
6. 关闭图层渐变：旧渐变层消失，退回原来选择的DYYY颜色；不会覆盖保存的自定颜色。
7. 重启App后检查开关持久化；对比滚动流畅度、发热和长时间播放。

CI成功只说明该提交编译和打包通过。不能据此保证抖音32.6私有类在每种注入环境下可达，
也不能保证像素级效果已与原图层真机对照。测试包请按CI提交SHA/产物校验值区分。
